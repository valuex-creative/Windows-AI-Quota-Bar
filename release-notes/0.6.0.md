### New
- **🖱️ Cursor.** See your Cursor plan's included usage (weekly or monthly, whichever your plan has) and when it resets. Click **Sign in** under Settings → Cursor and log in to cursor.com in your browser. The app keeps its own login, encrypted for your Windows user, and never reads Cursor's files. Contributed by @kspinfps, thank you!

Cursor shows up for everyone after the update. If you don't use it, turn it off in Settings.

Cursor's usage numbers come from the endpoints its own apps use, which aren't a public API. If Cursor changes them, this card may stop working until the next update.

### Install
Download **`WindowsAIQuotaBar-Setup-0.6.0.exe`** and double-click it. It installs for your user only and needs no admin rights or .NET. Earlier versions update themselves.

The in-app updater checks each installer's signature. Update-signing key fingerprint: `7d8b52a2253d4bbb99f303a4c94dc94f5e806827072e01ff5cd3a172edbaee13`.

The installer is not Authenticode-signed yet. If SmartScreen warns you, choose **More info → Run anyway**.
