### Fixed
- **🧠 High memory use with Antigravity.** If you use Google Antigravity, the app could grow to several GB of memory over a day. Each time an Antigravity sign-in was renewed, it loaded the whole `agy` program file (200+ MB) into memory. It now reads that file only when it has to, in small pieces. On the test PC, memory after startup went from about 760 MB to about 150 MB.

If you don't use Antigravity, nothing changes for you.

### Install
Download **`WindowsAIQuotaBar-Setup-0.5.1.exe`** and double-click it. It installs for your user only and needs no admin rights or .NET. Earlier versions update themselves.
